Рассылка изменений лимитов

По текущей принятой версии выбранного набора бот отправит каждому подписчику краткий список только его объектов с изменениями. Объекты без изменений не включаются. Одна версия рассылается один раз для каждого выбранного фильтра; доставка выполняется в фоне.

Фильтр действует для бота и его Excel-выгрузки: данные финансирования за более ранние годы скрываются. Остальные сведения об объектах не меняются.
