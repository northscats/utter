Рассылка изменений лимитов

По сохранённой версии файла бот отправит каждому подписчику краткий список только его объектов с изменениями. Объекты без изменений не включаются. Каждое подтверждённое нажатие создаёт новую рассылку, даже если версия и фильтр не изменились. Доставка выполняется в фоне.

Фильтр действует для бота и его Excel-выгрузки: данные финансирования за более ранние годы скрываются. Остальные сведения об объектах не меняются.

↗

Отправить изменения лимитов?

Бот MAX отправит подписчикам сообщения по их объектам с изменениями. Повторная отправка создаст новые сообщения, даже если данные и фильтр не изменились.
