# Проверка пилота приёма 1С

Проверено 8 сентября 2026 года в среде разработки:

* 9 тестов строгого парсера.
* 15 Flask/SQLite интеграционных тестов: права администратора и CSRF,
  создание единственного канала, одноразовые реквизиты/ротация, транспорт,
  образец из 49 строк и его шесть частей по ИНН, отказ смешанному пакету,
  изменяемые колонки, точные числа, пустые результаты, журнал, ограничения,
  идемпотентность, очистка при полном удалении предприятия.
* Принят и полностью прочитан отдельный текстовый элемент почти 8 МиБ —
  принятые значения не становятся недоступны из-за размера окна просмотра.
* 5 конкурентных тестов PostgreSQL в отдельной случайной схеме:
  единственность канала, одинаковые/разные параллельные пакеты,
  ротация/отключение во время обработки, отказ при занятости,
  чтение зафиксированного снимка через новое соединение.
* Существующий набор проверок справочника предприятий, включая полное
  удаление, аудит и повтор очистки файлов, прошёл без регрессий.
* Через публичный HTTPS preview выполнен настоящий POST с Basic Auth
  без открытой страницы администратора. Затем Chromium проверил создание,
  очистку одноразового пароля, таблицу 65 × 71, страницы строк и окон колонок,
  позднее поле, безопасный вывод HTML как текста, замену пустым результатом,
  запоздалый ответ ротации и повторное открытие доступных элементов управления.
  Проверены настольный и мобильный размеры. Временные записи теста удалены.

Команды из `osv-dashboard`:

```sh
python -m unittest test_one_c_integration test_one_c_push -q
python test_one_c_postgres.py
python test_company_directory.py
python test_one_c_browser.py --public-preview
```

Первые и третьи проверки используют собственную SQLite. PostgreSQL-проверка
создаёт и удаляет только случайную изолированную схему development БД.
Последняя проверка разрешена только для `.replit.dev`, временно создаёт
собственные записи администратора/предприятия и всегда удаляет их в `finally`;
требует установленного системного Chromium и Playwright.

## Граница выполненной проверки

Новая версия не опубликована этой работой. Полная проверка реальной сети 1С,
боевых реквизитов и постоянного хостинга должна выполняться после публикации
по [эксплуатационной инструкции](one-c-operations.md).
Неудачное подключение к HTTP порту из среды разработки не доказывает
недоступность HTTP из любой сети; приложение честно показывает эту неопределённость.
