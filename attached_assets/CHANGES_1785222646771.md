# Изменения кода, окружение и учётная запись

Документ описывает доработки для запуска ОСВ Дашборда в контейнере за Apache/nginx на подпути `/osv`, порт хоста **4545**.

---

## 1. Учётная запись администратора

При первом запуске (когда в таблице `users` ещё нет записей) автоматически создаётся:

| Поле | Значение |
|------|----------|
| Логин | `admin` |
| Пароль | `admin123` |

Создание происходит в `app.py` → функция `init_db()` (вызывается из `deploy/entrypoint.sh` при старте контейнера).

**Обязательно смените пароль сразу после первого входа.**

Пример смены пароля в контейнере:

```bash
podman exec -it app-web python - <<'PY'
import bcrypt
from app import app, db
from database import User

new_password = b"НовыйПароль"
with app.app_context():
    user = User.query.filter_by(username="admin").first()
    user.password_hash = bcrypt.hashpw(new_password, bcrypt.gensalt()).decode()
    db.session.commit()
    print("Готово")
PY
```

## 2. Окружение (переменные)

### Файл `.env` / `.env.example`

| Переменная | Назначение | Пример |
|------------|------------|--------|
| `POSTGRES_USER` | Пользователь PostgreSQL | `osv_user` |
| `POSTGRES_PASSWORD` | Пароль PostgreSQL | сложный пароль |
| `POSTGRES_DB` | Имя базы | `osv_db` |
| `SESSION_SECRET` | Секрет Flask-сессий | случайная строка ≥32 символов |
| `APP_PORT` | Порт на хосте | `4545` |
| `SCRIPT_NAME` | Подпуть приложения | `/osv` |
| `GUNICORN_WORKERS` | Число воркеров gunicorn | `2` |

### Переменные контейнера `web` (или `podman run`)

| Переменная | Назначение | Пример |
|------------|------------|--------|
| `DATABASE_URL` | Строка подключения к PostgreSQL | `postgresql://osv_user:ПАРОЛЬ@localhost:5433/osv_db` |
| `SESSION_SECRET` | Секрет сессий | `secret123` (замените!) |
| `SCRIPT_NAME` | Префикс URL | `/osv` |
| `PORT` | Порт внутри контейнера / при `--network host` | `4545` (host) или `8080` (bridge) |
| `GUNICORN_WORKERS` | Воркеры | `2` |

### Пример запуска через Podman (как на сервере)

**БД:**
```bash
sudo podman run -d \
  --name app-db \
  --restart unless-stopped \
  -p 5433:5432 \
  -e POSTGRES_USER=osv_user \
  -e POSTGRES_PASSWORD=postgres \
  -e POSTGRES_DB=osv_db \
  -v postgres_data:/var/lib/postgresql/data \
  postgres:16-alpine
```

**Приложение:**
```bash
sudo podman run -d \
  --name app-web \
  --restart unless-stopped \
  --network host \
  -e DATABASE_URL=postgresql://osv_user:postgres@localhost:5433/osv_db \
  -e SESSION_SECRET=secret123 \
  -e PORT=4545 \
  -e SCRIPT_NAME=/osv \
  -v uploads_data:/app/uploads \
  -v output_data:/app/output \
  docker.io/library/osv-dashboard-web:latest
```

### Apache (прокси на `/osv`)

Префикс **не срезать** — проксировать на тот же путь:

```apache
RedirectMatch ^/osv$ /osv/

ProxyPass        /osv/  http://127.0.0.1:4545/osv/
ProxyPassReverse /osv/  http://127.0.0.1:4545/osv/

RequestHeader set X-Forwarded-Proto expr=%{REQUEST_SCHEME}
RequestHeader set X-Forwarded-Port expr=%{SERVER_PORT}
```

Полный фрагмент: `deploy/apache-osv.conf`.

## 3. Изменения кода и файлов

### Новые файлы

| Файл | Назначение |
|------|------------|
| `Dockerfile` | Образ Python 3.11 + gunicorn |
| `docker-compose.yml` | Сервисы `db` + `web`, порт хоста 4545 |
| `.dockerignore` | Исключения при сборке образа |
| `.env.example` | Шаблон переменных окружения |
| `deploy/entrypoint.sh` | Ожидание PostgreSQL → `init_db()` → gunicorn |
| `deploy/apache-osv.conf` | Фрагмент VirtualHost для Apache2 |
| `deploy/nginx-docker.conf` | Опциональный nginx (если нужен) |
| `deploy/DOCKER.md` | Инструкция Docker/Podman + Apache |

### Изменённые файлы

| Файл | Что изменено |
|------|--------------|
| `app.py` | `PrefixMiddleware` для `SCRIPT_NAME=/osv`; `APPLICATION_ROOT` и `SESSION_COOKIE_PATH`; `ProxyFix` для `X-Forwarded-*` |
| `templates/login.html` | Ссылки/формы через `url_for(...)` вместо жёстких `/login` |
| `templates/home.html` | То же: `url_for` для logout, company, new |
| `templates/company.html` | То же: rename, upload, dashboard, logout |
| `templates/company_new.html` | То же: home, company_new |
| `deploy/DEPLOY.md` | Ссылка на Docker-инструкцию |

### Суть правки в `app.py`

Раньше при работе за прокси ссылки вели в корень домена (`/login`, `/company/...`).

Теперь при `SCRIPT_NAME=/osv`:
1. Middleware монтирует приложение под `/osv`;
2. шаблоны генерируют URL через `url_for` → `/osv/login`, `/osv/company/...`;
3. cookie сессии ограничены путём `/osv`.

### Суть правок в шаблонах

Заменены абсолютные пути вида `href="/logout"` на `href="{{ url_for('logout') }}"` (и аналогично для остальных маршрутов), чтобы префикс `/osv` сохранялся при кликах.

## 4. Краткая проверка

```bash
# контейнер напрямую
curl -I http://127.0.0.1:4545/osv/login
# ожидается: 200 или 302

# через домен
curl -I https://uzter.mosreg.ru/osv/login
# ожидается: 200 или 302
```

Вход: **https://домен/osv/login** → `admin` / `admin123`.

## 5. Podman и выход из SSH

Чтобы контейнеры не останавливались при logout:

```bash
# rootless
loginctl enable-linger $USER

# или systemd из существующих контейнеров (rootful)
sudo podman generate systemd --new --files --name app-db
sudo podman generate systemd --new --files --name app-web
sudo systemctl daemon-reload
sudo systemctl enable --now container-app-db.service
sudo systemctl enable --now container-app-web.service
```

Проверка после reconnect: `sudo podman ps` (не без `sudo`, если запускали от root).
