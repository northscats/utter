---
name: Осиротевший процесс Gunicorn после слияния
description: Конфликт порта workflow приложения ОСВ после автоматического слияния.
---

При ошибке запуска управляемого workflow с `Address already in use` порт может удерживать Gunicorn, который больше не принадлежит workflow, хотя preview продолжает отвечать. Не считать один успешный HTTP-ответ подтверждением успешного управляемого перезапуска.

**Why:** После нескольких слияний старый Gunicorn продолжал обслуживать preview, а новая копия управляемого workflow не могла занять порт. Старый процесс потенциально обслуживал устаревший код.

**How to apply:** Проверить статус workflow, PID и рабочую директорию процесса на порту; завершать только подтверждённый старый Gunicorn, затем один раз запустить точный managed workflow и проверить его готовность. Не создавать второй workflow и не менять порт приложения.
