---
name: Изоляция тестов Flask
description: Почему автономные наборы тестов с временной SQLite нельзя объединять в один процесс
---

Автономные наборы тестов, задающие временную SQLite перед импортом общего Flask-приложения, запускать отдельными процессами. Контекст приложения для подготовки БД не должен охватывать запросы разных тестовых клиентов.

**Why:** Импорт приложения фиксирует подключение на весь процесс. Очистка временной папки одним набором ломает БД следующего; общий контекст также сохраняет `current_user` Flask-Login, вызывая ложные перенаправления на вход у авторизованного клиента.

**How to apply:** При проверке нескольких таких наборов использовать отдельную команду Python для каждого. Ограничивать контексты подготовки данных и освобождать их перед HTTP-запросами; не ослаблять проверку прав ради ошибочного тестового ответа.
