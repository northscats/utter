SQL-пакеты для продакшена предназначены для внешнего PostgreSQL, а не встроенной базы Replit.

**Why:** Владелец явно подтвердил внешний PostgreSQL 2026-09-29 при запросе миграции за 24–29 сентября.

**How to apply:** Готовить отдельные проверяемые пакеты, не выполнять их на проде без разрешения. Не считать успешный аддитивный SQL доказательством безопасности запуска нового приложения: отдельно проверять startup-очистку старых таблиц и перенос прав MAX. Не угадывать соответствие старых получателей новым user_id/UIN.
