---
name: Режимы поиска мощности аналогов
description: Совместимость нового фильтра мощности со старым API каталога аналогов.
---

Параметр нового пользовательского поля мощности должен возвращать только аналоги в допустимом отклонении. Старый API-параметр мощности сохраняет прежний режим: весь каталог с ранжированием по близости и признаком соответствия.

**Why:** Старый режим используется для пагинации полного каталога; превращение его в строгий фильтр незаметно меняет общее число записей и ломает совместимость клиентов.

**How to apply:** При изменении разбора или SQL-запроса мощности отдельно проверять строгий поиск через новое поле и полную пагинацию через устаревший параметр.
