---
name: Русская группировка в SQLite
description: Как надёжно классифицировать групповые подписи на кириллице при совместимости с SQLite.
---

Не рассчитывать на SQL `lower()` для сравнений русских подписей в SQLite: встроенное преобразование регистра не обрабатывает кириллицу. Для новых импортируемых строк классифицировать такие подписи в Python и сохранять явный признак, если фильтры и сводки должны работать на разных СУБД.

**Why:** SQLite оставил «Прочие» с заглавной буквы при `lower()`, из-за чего групповой отчёт ошибочно попал в счётчик организаций без ИНН.

**How to apply:** При импорте нормализовать русские текстовые метки через Python `casefold()` и применять сохранённую классификацию в агрегатах; не возвращать кириллическое `func.lower()`-сопоставление.
