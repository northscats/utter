---
name: Выбор периодных ОСВ
description: Правила выбора между полным и узким отчётом и расчёта интервала из накопительных ОСВ
---

Для одного интервала полный отчёт родительского счёта имеет приоритет над более поздним узким отчётом одного субсчёта. Период можно получить разностью накопительного отчёта и полностью покрытого предшествующего интервала.

Для прокси собираемости по счёту 62 использовать дневные обороты, если в интервале явно присутствуют и 62.01, и 62.02. Периодная иерархия с ограниченной глубиной может одновременно материализовать родителей и потомков и завысить оборот.

**Why:** Узкий отчёт 90.01 вытеснял полный счёт 90 и скрывал существующие строки НДС 90.03. Для счёта 62 усечённая периодная иерархия завысила ОбД 62.01, хотя сумма дневных строк точно сходилась с итогом XLS.

**How to apply:** При равных датах сначала сравнивать полноту охвата субсчетов, затем ревизию источника. Для разности не распределять агрегат пропорционально дням. В собираемости переходить на дневной источник только при наличии обоих обязательных субсчетов.
