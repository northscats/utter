---
name: Выбор периодных ОСВ
description: Правила выбора между полным и узким отчётом и расчёта интервала из накопительных ОСВ
---

Для одного интервала полный отчёт родительского счёта имеет приоритет над более поздним узким отчётом одного субсчёта. Период можно получить разностью двух накопительных отчётов только при одинаковой начальной дате и точной границе вычитания.

**Why:** Узкий отчёт 90.01 вытеснял полный счёт 90 и скрывал существующие строки НДС 90.03. При этом некоторые интервалы доступны только как разность накопительного отчёта и полного отчёта за предшествующую часть.

**How to apply:** При равных датах сначала сравнивать полноту охвата субсчетов, затем ревизию источника. Для разности не распределять агрегат пропорционально дням: вычитать только отчёт с тем же началом, заканчивающийся накануне нужного периода.
