---
name: Доверие к сертификату API MAX
description: Проверка TLS для MAX API в среде Replit
---

У домена API MAX сертификат, подписанный цепочкой Минцифры; системный набор удостоверяющих центров в этом окружении не содержит Russian Trusted Root CA. Простой HTTPS-запрос Python к API завершается ошибкой проверки цепочки при рабочем токене.

**Why:** Без доверенного корня бот не подключается, хотя токен действителен. Официальный корневой сертификат доступен на gu-st.ru/content/Other/doc/russian_trusted_root_ca.cer; его SHA-256 fingerprint: D2:6D:2D:02:31:B7:C3:9F:92:CC:73:85:12:BA:54:10:35:19:E4:40:5D:68:B5:BD:70:3E:97:88:CA:8E:CF:31.

**How to apply:** При смене HTTP-клиента или окружения сохранять проверку цепочки и имени узла; если системное доверие по-прежнему не настроено, загружать проверенный корень только для соединений с MAX. Никогда не заменять это на отключение проверки сертификата.
