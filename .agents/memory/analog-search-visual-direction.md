---
name: Визуальное направление поиска аналогов
description: Оценка владельцем дизайна и ограничение по палитре для модуля аналогов.
---

Модуль поиска объектов-аналогов должен оставаться светлым и простым для длительной работы с таблицами; избегать тёмных цветовых блоков и тёмной темы. Владелец оценил прежнее оформление на 4/10 и прямо попросил улучшить его без тёмных цветов.

**Why:** Нейтральной перестановки полей недостаточно: запрос касается качества восприятия всего модуля, при этом тёмная палитра явно отклонена.

**How to apply:** При последующих правках поиска, каталога и импорта соблюдать светлое визуальное направление, сохранять читаемость данных и проверять мобильную компоновку.
