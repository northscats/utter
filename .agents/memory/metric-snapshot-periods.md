---
name: Периоды снимков метрик
description: Как выбирать даты при предварительном расчёте показателей
---

Предварительно рассчитанные показатели нужно привязывать к тем вариантам даты, которые принимает текущий серверный расчёт, а не к предполагаемым концам месяцев из отдельных аналитических строк. Сравнения должны использовать фактические границы, возвращённые расчётом.

**Why:** На реальных ОСВ МУП КГХ даты внутри отдельных строк не совпали с набором доступных пользователю периодов: календарное перечисление и выбор максимальной даты отдельных строк выдавали ошибки «date is not an available option». Неверный период привёл бы к отсутствующему или ошибочно сопоставленному снимку.

**How to apply:** При изменении механизма выбора дат обновлять генерацию снимков синхронно с серверным селектором; проверять хотя бы один ранний период на большом реальном наборе, а не только на синтетических датах.
