---
name: Изоляция операционной диагностики
description: Правило транзакционной границы для технических журналов внешних интеграций.
---

Best-effort диагностический журнал внешней интеграции должен записываться
отдельной короткой транзакцией и никогда не вызывать commit или rollback
request-scoped бизнес-сессии.

**Why:** Иначе техническое событие может незаметно зафиксировать незавершённые
доменные изменения либо откатить их при собственной ошибке.

**How to apply:** Для ограниченных операционных событий использовать отдельное
соединение/сессию; сбой записи только логировать и не менять результат основной
операции.
