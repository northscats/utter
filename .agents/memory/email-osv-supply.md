---
name: Почтовая поставка ОСВ
description: Базовый регламент массовой поставки ОСВ по электронной почте
---

Основной почтовый пакет предприятия должен быть накопительным с 1 января по текущую дату и содержать группировку по дням. Отдельная полная сводная ОСВ используется как контрольный снимок периода.

**Why:** Письмо только за один день не восстанавливает пропущенную доставку и не отражает проводки, исправленные задним числом. Накопительный пакет сам закрывает оба случая, но его нельзя суммировать с предыдущими версиями.

**How to apply:** Хранить каждый исходный пакет неизменно, определять дубли по байтовому и смысловому хешу, а разные файлы одного периода принимать как ревизии. Активировать данные только после атомарной валидации и сверки с контрольной сводной ОСВ.
