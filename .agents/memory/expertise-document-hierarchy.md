---
name: Иерархия заключений экспертизы
description: Как сохранять дерево состава документации 3.1.1, когда XML содержит только листья.
---

В подписанных XML заключений порядковые номера документов могут ссылаться на разделы, для которых отдельной строки в источнике нет. Такие разделы следует создавать как синтетические узлы текущей версии и связывать листья через родительский идентификатор.

**Why:** Одного вычисленного текста `parent_ordinal` недостаточно: он не сохраняет дерево в базе и не позволяет надёжно показывать разделы, подразделы и версии независимо.

**How to apply:** При импорте сначала собрать недостающие родительские номера, создать version-scoped узлы разделов, затем после flush связать документы с родителями. Не смешивать узлы разных версий паспорта.
