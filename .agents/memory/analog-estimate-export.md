---
name: Выгрузка сметы аналога
description: Особенность присланного пользователем примера НМЦК и границы подтверждаемой разбивки.
---

В присланном примере НМЦК строка «СМР по главам 1–8» численно равна сумме строк «строительные», «монтажные» и «пусконаладочные», несмотря на то, что в других загруженных ССР пусконаладка может стоять в главе 9. Нельзя получать эту строку простым сложением итогов глав или считать, что отсутствие отдельной позиции равно нулю. Общая графа «Оборудование» в ССР не доказывает, что всё оно технологическое.

**Why:** Владелец попросил выгрузку по предоставленному XLSX для каждого аналога, с последующей проверкой и доработкой результата; в примере суммы СМР и ПИР сходятся по указанным подстрокам, но сами исходные значения в XLSX записаны константами, а не формулами. Приписывание этой разбивки другим объектам без исходных строк ССР дало бы недостоверные суммы.

**How to apply:** Для каждого объекта брать только его текущую утверждённую версию, оставлять неподтверждённые суммы пустыми и указывать происхождение каждой заполненной позиции. Помечать всё оборудование из общей графы как требующее уточнения.
