---
name: Имена выдаваемых файлов
description: Ограничение регистрации скачиваемых файлов с кириллицей в пути
---

Для выдачи документа через presentAsset использовать ASCII-имя физического файла, если кириллица вызывает UPLOAD_FAILED / ByteString. Русское название сохранять в title; оригинал с русским именем можно оставить в exports.

**Why:** Регистрация нативного DOC с кириллицей в пути завершилась ошибкой преобразования ByteString; идентичная бинарная копия с ASCII-именем зарегистрировалась успешно.

**How to apply:** Это ограничение доставки, не повреждение документа. Не пересобирать содержимое и не менять формат; выдать копию с совместимым именем.
