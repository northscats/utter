---
name: Размер образа публикации
description: Как не превысить лимит образа из-за транзитивных Nix-зависимостей.
---

Не включать Chromium, Playwright driver и компиляторы в системные runtime-зависимости, если они нужны только тестам или локальной сборке. Сохранять в production только реально используемые обработчиками документов инструменты.

**Why:** Размер Nix-пакета существенно меньше размера его полного closure. Одновременное включение офисного пакета, OCR, браузера и инструментов сборки превысило лимит образа 8 GiB, хотя файлы проекта занимали менее 2 GiB.

**How to apply:** При ошибке размера образа проверять closure системных зависимостей, а не только `du` рабочего каталога. Браузерные тесты не должны определять состав production-образа.

Не считать `Retrieved cached nix layer` доказательством полного попадания в кэш. Оценивать системный слой по всей последовательности событий и длительности, отдельно от компиляции приложения.

**Why:** В журналах публикации получение кэшированного слоя может соседствовать с `Nix layers for this Repl are uncached` и длительным созданием `nix-0`. Эти сообщения не раскрывают точную причину частичного промаха кэша.

**How to apply:** Сравнивать временные отметки проверки Nix, `Pushing nix-0` и `Created nix-0`; учитывать параллельную упаковку Repl, не складывая пересекающиеся интервалы. Корневой package.json build не считать активным этапом без подтверждения конфигурацией публикации или журналом.

Для диагностики существующего окружения запрашивать метаданные известных store paths одним вызовом Nix и обходить references в памяти, а не делать отдельный процесс на каждый путь.

**Why:** Последовательные запросы сотен зависимостей слишком медленны; NAR-размер wrapper не равен размеру его транзитивных зависимостей. Локальный NAR также не равен размеру production-слоя.

**How to apply:** Получить реальные paths через доступные бинарники, затем пакетный `nix path-info --json` для объединения их requisites. Суммировать уникальные пути; проверять, что размер объединения не превышает сумму отдельных групп.

При сокращении OCR-окружения сохранять русский, английский и данные определения ориентации, а уменьшать именно зависимости Nix-пакета.

**Why:** Полный пакет Tesseract может удерживать модели всех языков прямой ссылкой; смена TESSDATA_PREFIX не освобождает эти данные из closure. Ориентация страниц использует отдельную модель OSD.

**How to apply:** При реализации узкого набора проверить все объявления Tesseract, чтобы альтернативный корень не удерживал полный пакет; проверить OCR и поворот страниц до публикации.

При сокращении системных пакетов не удалять секцию `[nix]` целиком: сохранять канал и управлять минимальным списком через установщик системных зависимостей. Валидированная замена `.replit` может нормализовать конфигурацию и убрать отдельный `replit.nix`.

**Why:** Полное удаление `[nix]` временно убрало Python из PATH новых shell-команд. Возврат канала с минимальным списком восстановил языковые модули, сохранив уменьшенный production closure.

**How to apply:** Оставлять `channel`, удалять development-only пакеты и затем явно устанавливать только runtime-инструменты. После изменения проверять наличие Python и нужных CLI, dependency checker и запуск workflow.
