---
name: Пустые ОСВ 1С
description: Как трактовать типовой пустой отчёт 1С без отдельной строки номера счёта.
---

Типовая пустая ОСВ 1С с заголовком «Оборотно-сальдовая ведомость по счету …» и единственной строкой «Итого» является предоставленным отчётом, а не повреждённым файлом. Номер счёта следует определять из заголовка; строки, движения и остатки должны оставаться пустыми или нулевыми, без выдуманных значений.

**Why:** Реальная выгрузка пустого счёта не содержала отдельной строки с номером счёта, из-за чего один допустимый файл блокировал экран показателей всего предприятия.

**How to apply:** При изменении парсера сохранять строгую ошибку для неизвестных книг, но разрешать fallback по номеру счёта только для узнаваемого заголовка ОСВ или строгого имени файла. Пустой отчёт учитывать в комплектности и помечать понятным предупреждением.
