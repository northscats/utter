---
name: Кэш источника произвольного диапазона
description: Граница быстрого чтения показателей и строгого вычисления по ОСВ
---

Для произвольных диапазонов сохранять принятую версию разобранного источника отдельно от скалярных периодных снимков; отсутствие или устаревание этой версии не должно превращаться в чтение исходных файлов внутри HTTP-запроса.

**Why:** Построение источника большого предприятия требует секунд на чтение файлов. При смене дат промах процессного кэша снова блокировал экран и конкурировал с другими запросами.

**How to apply:** Пересборку источника публиковать атомарно после проверки ревизии и делать вне запроса. Для аналитических карточек хранить достаточно деталей, чтобы бухгалтерская методика не изменилась; префиксы дневных оборотов использовать только при доказанной полноте и известности каждого дня и поля. Сальдо по датам не складывать, а брать из достоверных граничных наблюдений.

Прогрев разбираемого источника не должен переключать активный указатель на скалярную публикацию.

**Why:** После новой загрузки прогрев может пройти, а полный расчёт показателей — упасть. Если прогрев заменит публикацию исходным кэшем без значений, сравнение потеряет прежние подтверждённые показатели.

Поколение задания и ревизию данных источника нужно разделять. Повторная постановка задания после запуска не обязательно означает изменение файлов или суточных фактов; если считать её новой ревизией источника, уже готовый кэш станет «устаревшим» и экран временно получит 503.

**Why:** При восстановлении очереди в рабочем окружении поколение несколько раз менялось без подтверждённой новой загрузки; прогретый источник каждый раз приходилось заново публиковать, пока карточки оставались недоступны.

**How to apply:** Для разбираемого источника использовать отдельную долговечную ревизию фактов, меняющуюся только при реальной записи Upload/DailyRow. Поколение очереди оставлять для защиты от гонки фоновых расчётов. При смене методики или повторе задания не сбрасывать источник без оснований.

**How to apply:** Хранить источник независимо от указателя на опубликованные значения и сравнивать его ревизию перед чтением. Старый снимок остаётся активным до успешной атомарной пересборки.
