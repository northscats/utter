---
name: Производительность основных показателей
description: Правила для крупных ОСВ с тысячами аналитик в основном финансовом экране
---

Определение терминальных строк иерархии должно использовать индексы префиксов, а не попарное сравнение каждой строки со всеми остальными.

**Why:** На предприятии с тысячами аналитик счёта 62 квадратичный проход превращал обычную загрузку основных показателей в ожидание около двадцати секунд.

**How to apply:** Любую новую проверку родительских и дочерних строк строить через заранее рассчитанные множества кодов и префиксов аналитик; обязательно измерять на крупном реальном источнике.

Основной ответ не должен дублировать полные аналитические записи и строить отдельные временные ряды для тысяч строк.

**Why:** Дубли дебиторской аналитики и индивидуальные серии увеличивают расчёт, JSON и время передачи, хотя начальный экран использует общий ряд.

**How to apply:** Полную таблицу хранить в одном поле, проблемные списки делать компактными, а индивидуальные серии ограничивать для крупных наборов. Большие JSON-ответы передавать со сжатием.
