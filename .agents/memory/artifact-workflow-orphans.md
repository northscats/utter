---
name: Зависшие процессы artifact workflow
description: Как отличить неверный порт от старой группы процессов, оставшейся после неудачного запуска artifact workflow.
---

Если artifact workflow падает с `EADDRINUSE`, хотя его конфигурация уже использует собственный `localPort` и переданный `PORT`, сначала проверить процессы и их группы. Старый процесс сервиса может продолжать слушать порт, пока workflow уже помечен как failed.

**Why:** повторные перезапуски создавали новые экземпляры Vite и Node, которые падали на занятых портах 8081 и 8080; старые группы процессов при этом оставались живы.

**How to apply:** сопоставить слушающий процесс с конкретным artifact-сервисом, остановить только его старую process group, затем по одному перезапустить управляемые workflow и подтвердить каждый путь HTTP-запросом.
