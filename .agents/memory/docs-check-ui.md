Эталонный интерфейс модуля — в архиве `attached_assets/mbt-service_1_1785772166812.zip`, файл `mbt-service_1/client/src/pages/MbtProjectPage.tsx` (React). При спорах о «как было в исходном проекте» сверяться с ним, а не придумывать.

**Принятая раскладка рабочего экрана пакета** (docs_check.html): три панели — слева список файлов по каталогам, в центре постраничный просмотр с пейджером (клавиши ←/→), справа вертикальная лента миниатюр. Кнопки «Согласовать» (approved/approved_at в DocFile, POST /docs/files/<id>/approve — строго boolean) и «▶ Запустить анализ». После загрузки ZIP — автопереход в этот экран.

**Why:** пользователь требует соответствия исходному mbt-проекту; отдельные экраны «пакет» и «файл» были признаны расхождением.

**How to apply:** любые изменения UI модуля не должны возвращать табличный/многоэкранный вид; при selectFile использовать токен wsSelectSeq против гонок при быстром переключении.

**Расширение (полное соответствие эталону, август 2026):** находки ИИ показываются чипами под предпросмотром + цветными точками на миниатюрах (координатных оверлеев нет — исходник их тоже не рисует поверх изображения точно). Легенда Даты/Подписи/Печати кликабельна (скрытие типа). OCR-переключатель из эталона сознательно опущен — OCR в нашем пайплайне автоматический (примечание в поповере параметров анализа). Отчёт/XLSX — единый эндпоинт /docs/report(/export); старый /docs/packages/<id>/export больше не используется UI. ZIP >5 МБ грузятся чанками (init/chunk/finalize).
