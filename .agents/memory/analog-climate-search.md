---
name: Совместимость климатических обозначений в быстром поиске
description: Границы нормализации ручного ввода и исторического режима поиска по региону.
---

В точном поиске района латинские A и B в обозначениях следует сопоставлять с кириллическими А и В, не объединяя В с Б. Режим поиска по укрупнённому региону следует сохранять отдельно от этой нормализации.

**Why:** Пользователь может набрать визуально совпадающее обозначение в латинской раскладке; расширение поиска по региону затронуло бы старых клиентов API и сменило состав их выдачи.

**How to apply:** При изменении поиска аналогов проверять точный район и регион независимо, в том числе совместное использование обоих параметров.

Подсказки быстрого поиска должны показывать полный перечень подрайонов из предоставленного владельцем списка, даже если в текущем каталоге нет объектов для некоторых из них; дополнительные значения действующих объектов также сохраняются в подсказках, без описаний.

**Why:** Владелец уточнил, что подсказок из одного только текущего каталога недостаточно. Отсутствующий в каталоге район при выборе даёт обычную пустую выдачу.

**How to apply:** При корректировке подсказок не ограничивать их только активными записями и не добавлять климатические описания в варианты выбора.
