---
name: ОХР до закрытия периода
description: Источник общехозяйственных расходов для ещё не закрытого бухгалтерского периода.
---

Для закрытого периода использовать дебетовый оборот 90.08. Если в выбранном
периоде 90.08 ещё не сформирован, использовать дебетовый оборот счёта 26 как
подтверждённые формирующие ОХР.

**Why:** До регламентного закрытия месяца общехозяйственные расходы остаются на
счёте 26. Требование только 90.08 ошибочно показывает отсутствие данных для
текущего неполного месяца.

**How to apply:** Резервный источник 26 допустим только при отсутствии
подтверждённого оборота 90.08; явный нулевой 90.08 не заменять.
